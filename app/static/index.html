#OpenSourceHiggsfield

Scan it. Clone it. Vaporize it.

Higgsfield-style video effects, rebuilt in the open on ComfyUI. Every effect is a node graph you can open and change, and it runs on open-weight models with no GPU required.

1Pick an effect and drop in a clip (or use a sample).
2The app runs the effect's ComfyUI workflow through the Comfy SDK.
3Download the video, or grab the exact workflow to remix in ComfyUI.
Built with ComfyUI, Depth Anything 3 (Apache-2.0) and BiRefNet (MIT). Open weights only, Apache-2.0 code.
